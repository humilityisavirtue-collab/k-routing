01

Self-Built AI Coding Agent

terminal · multi-provider

  • Python
  • ~15.5K LOC
  • agentic tool-use loop
  • MCP server
  • multi-provider routing

A terminal-based AI coding agent — functionally a self-made alternative to Claude Code / Cursor. Takes natural language, plans, and acts through a tool-use loop: read / write / edit files, run shell commands, and semantic + literal code search. Exposed as an MCP server, in active daily use.

Why I built it
I wanted full control over the hooks, the agent loop, and tool dispatch — the extension points existing agents don't expose. Owning the loop end-to-end made the rest possible.
Loop-detection
A "doom-loop" abort that doesn't just check for repetition — it asks whether each turn makes progress. A true loop goes nowhere and gets killed; productive iteration revisits the same ground but advances.
Tiered budgets
free → enterprise: 3 / 8 / 24 / 64 max-turns, scaling RAG-file count, context budget, and history recall per tier.
Multi-provider
Routing across Claude, Gemini, local Ollama, OpenAI, and Groq. Undo on every file write, append-only audit log.

02

Multi-Agent Orchestration System

typed message-bus · compile-time validated

  • Python
  • typed conditional edge-router
  • event-driven state
  • static topology linter
  • cost + liveness tracking

The system the coding agent runs within: role-specialized agents coordinating over a typed message bus. A first-match dispatcher routes work on (source × message-type) to a target agent across ~16 message types and 4 trust tiers, with per-agent cost + liveness tracking and an append-only audit log — the "deterministic backbone, LLM at the nodes" pattern production frameworks converged on in 2026.

Rigor
The router topology is validated at commit time by a linter I wrote — role-exists, trust-valid, dead-rule, and first-match-shadow detection — proven non-vacuous against a deliberately-broken fixture: the real config passes, planted defects fail.
Highlight
The tradeoffs between a shared mutable state store and message-passing, and agent liveness/failure detection — don't declare a worker dead from a single stale signal.
03

LLM Inference & Quantization Runtime

framework-free forward pass

  • custom quantized format
  • on-device NPU
  • fidelity gate

A forward-pass runtime that runs transformer models (Hermes-3-8B class) without a heavyweight ML framework, from a custom circuit-aware quantized format, with a fidelity gate that verifies outputs against a reference.

Problem
Running capable models on constrained/heterogeneous hardware (consumer GPU + AMD NPU) where the naive fp16 path doesn't fit.
Decisions
Treat the quantization format as a precision codec — naive low-bit is too lossy; a hybrid-precision tier runs in ~12GB and passes a fidelity gate, with a calibrated quantizer as the next step.
Highlight
The memory math (why fp8→fp16 upcast doubles footprint and OOMs), and offloading the right ops to NPU vs CPU vs GPU.

Held ↗

offline-first PWA

  • SvelteKit 2
  • Svelte 5 runes
  • Supabase
  • AES-256-GCM
  • Vercel

A production PWA that works fully offline via localStorage and syncs to the cloud when authenticated, with user data encrypted at the field level before it ever leaves the device.

Problem
Privacy-preserving sync — the server never sees plaintext user data.
Decisions
Hybrid storage (localStorage is the offline source of truth; debounced cloud sync; cloud-wins merge on auth); PBKDF2 key derivation + AES-256-GCM; stale-while-revalidate service worker.

06

Fix.Kit — Accessibility Compliance

browser-native · live DOM remediation

  • Chrome extension
  • WCAG 2.1
  • live DOM repair
  • BYOK alt-text
  • no backend

A browser tool that scans any website against 19 WCAG 2.1 success criteria and auto-repairs 13 of them live in the page — contrast, form labels, ARIA landmarks, heading structure, alt text — with a compliance score you watch change in real time. No backend; nothing leaves the page.

Honest scope
Measured F→C on the demo (score 0→68, 12 live fixes); anything it can't safely auto-fix — complex image descriptions, third-party widgets, PDFs — it flags rather than fakes. No false confidence.
Why
California's Unruh Act (and AB-2190, effective 2027) make web accessibility a legal bar for businesses — this is the fast, private, on-the-spot path to compliant.
